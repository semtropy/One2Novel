# MVP 实施与验收范围

依据 TECHNICAL_PLAN 第1节，首个可用版本以连续两章的可靠生产闭环为边界，覆盖 P1～P4，并提前提供历史重写与导出。完整 V2 的 Reference/Knowledge 导入工作台、批次生产、长篇检索优化和备份恢复为后续阶段，不以空页面冒充实现。

核心验收：创建小说 → 生成并人工确认开书方案/初始事实 → 生成章计划与正文 → required Evaluator 全部通过 → 独立事件抽取与状态验证 → 原子提交 → 下一章引用正确 head。没有模型配置仍能启动和编辑；真实模型效果与离线可靠性测试分开记录。

界面：白色 #ffffff，纸面 #fafbfc，墨色 #242833，次级灰 #747b87，边线 #e9ecf0，强调蓝 #4566a8。界面使用系统无衬线字体，小说标题和正文使用本机宋体/思源宋体回退。书架 → 左章目录 / 中央稿纸 / 右侧规划与审核；章序和已提交标记承担导航，避免装饰性仪表盘。

规范仍以 DEVELOPMENT_SPEC 为准。交付时 README 与验收记录必须注明真实实现范围、测试证据和未验证项。
